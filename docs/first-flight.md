# เที่ยวบินแรกจากแผนที่ไปวิทยุ Saturn

ที่หน้า **My universe** เลือก **ลองบิน · Saturn → Titan** เพื่อเปิดแผนที่ระบบสุริยะ เลือก **บินไป Saturn** แล้ว **บินไป Titan** หรือเลือกดาวที่ขีดเส้นใต้บนแผนที่เอง ระหว่างทางยังใช้ล้อหรือแถบ **คุมการบิน** ได้ **ออกจากเส้นทาง** จะจบคำแนะนำที่จุดล่าสุดที่บินถึง หากกำลังเลื่อนแถบค้างไว้ จะกลับไปจุดที่เริ่มช่วงนั้น

เมื่อถึง Titan เลือก **ไปวิทยุ Saturn** ถ้ามีเพลงเล่นอยู่ ปุ่มจะระบุว่าจะพักเพลงก่อนเข้า วิทยุรอให้กด **Power on** ปุ่ม **กลับ Titan** และปุ่มย้อนกลับของเบราว์เซอร์พากลับมาที่ดาว กด **เล่นต่อ** เพื่อฟังเพลงเดิมจากตำแหน่งที่พักไว้

## ผลที่ตรวจบน Cloud

นับการกดจากหน้าแรกจนเห็นหน้าเครื่องรับในสถานะ Standby ใช้จอสัมผัสจำลอง 320 × 568 และ 390 × 844 กับเมาส์ที่ 1200 × 800

| จุดที่ถึง | เส้นทางเดิมที่เปิดดาวตามผัง | เส้นทางลองบิน |
| --- | ---: | ---: |
| Saturn | 3 | 2 |
| Titan | 4 | 3 |
| ห้องวิทยุ | 6 | 4 |

เส้นทางเดิมบน Chromium เริ่มจากทางช้างเผือก ผ่านระบบสุริยะ ไป Saturn และ Titan แล้วย้อนกลับ Saturn เพื่อเปิดวิทยุ เส้นทางใหม่เปิดห้องวิทยุได้จาก Titan ตัวเลขมาจากการทดสอบเบราว์เซอร์ ยังไม่มีข้อมูลเวลาที่ผู้ใช้ครั้งแรกใช้ค้นพบปุ่ม

- Chromium 156.0.8078.79, Playwright WebKit 26.5 และ Firefox 153.0 ผ่านเส้นทางปกติ การแวะ Earth การออกกลางทาง การเปิดลิงก์วิทยุโดยตรง การใช้ Tab/Enter โหมดลดการเคลื่อนไหว และ Back/Forward
- MP3 ทดสอบจาก Tide ใช้ตัวเล่นเดิมตลอดเที่ยวบิน การพักเสียงตอนเข้าวิทยุและกดเล่นต่อเมื่อกลับ Titan วัดได้ 5.90 → 5.95 วินาทีบน Chromium, 6.47 → 6.55 บน WebKit และ 6.19 → 6.23 บน Firefox ในรอบบนเว็บ Chromium ตรวจล้อจริงจาก Playwright กับเพลงเดโม Afterglow เพิ่มด้วย
- ชุดทดสอบเดิมตรวจการค้นหา Titan และเพลงท้องถิ่น การส่งออกและนำเข้าคลัง `.pgalaxy` ในโปรไฟล์ใหม่ และการสลับเพลงไปแล้วกลับมาเล่นต่อ [ทดสอบการค้นหา](../checks/search.py) · [ทดสอบคลังและเสียงข้ามเบราว์เซอร์](../checks/engines.py)

## ทดสอบซ้ำ

จากโฟลเดอร์โปรเจกต์ ใช้ Python, Playwright พร้อมเบราว์เซอร์ที่เลือก และ FFmpeg สำหรับสร้างไฟล์เสียงทดสอบ Firefox บน Linux ต้องมีเอาต์พุตเสียงที่เวลาฟังเดินได้

```sh
python3 checks/first_flight.py --browser chromium --baseline
python3 checks/first_flight.py --browser chromium --evidence /tmp/playlist-flight-images
python3 checks/first_flight.py --browser webkit
python3 checks/first_flight.py --browser firefox
```

ตัวเลือก `--url` รับ URL ของเซิร์ฟเวอร์รุ่นอื่นหรือ URL `file:` ของหน้า **Playlist Galaxy.html** ที่แตก ZIP แล้ว เมื่อใช้ไฟล์ ชุดทดสอบปิดคำขอ HTTP และ HTTPS ภาพก่อนและหลังอยู่ในโฟลเดอร์ **evidence** ของ ZIP [ชุดทดสอบเส้นทาง](../checks/first_flight.py)

## พร้อมให้ลอง และสิ่งที่รอผล

พร้อมรับฟีดแบ็กบนสาขาทดลอง หลักฐานมาจากเอนจินเบราว์เซอร์บน Linux กับเสียงทดสอบ ยังไม่ได้ลองบน iPhone หรือ Android เครื่องจริง

1. ให้คนที่ยังไม่รู้ผังเริ่มจากหน้าแรกและลองหาวิทยุ สังเกตว่าเห็นปุ่มลองบินเองไหม และเข้าใจว่าเพลงจะพักตรงไหน ก่อนพิจารณาเพิ่มข้อความหรือเส้นทาง
2. บนโทรศัพท์จริง ลองใช้นิ้วโป้งที่ขอบจอ ล็อกจอระหว่างฟัง MP3 แล้วกลับจากวิทยุผ่าน Back ตรวจเสียงผ่านลำโพงและหูฟัง รวมถึงการเปิด ZIP จากแอปไฟล์ [รายการตรวจ Safari/iPhone](browser-compatibility.md)
